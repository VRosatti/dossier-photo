# Dossier photographique

Application web pour situer des photos sur des plans PDF (point de vue + direction) et produire un dossier PDF numéroté.

- Tout fonctionne dans le navigateur : plans et photos restent sur l’appareil (sauvegarde automatique locale).
- Pour changer d’appareil : Projet > Enregistrer le fichier projet (.json), puis Ouvrir un fichier projet sur l’autre appareil.
- Bibliothèques incluses dans `lib/` (pdf.js 3.11.174, jsPDF 2.5.1) : aucun appel à un service extérieur.

Mise en ligne : déposer `index.html`, `README.md` et le dossier `lib/` dans un dépôt GitHub, puis activer GitHub Pages.
